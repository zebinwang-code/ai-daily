## 公众号

### 标杆：歸藏 × 宝玉xp

**歸藏（工具/产品层 AI 快讯）**

实际写法信号（来自 author-methods.md）：

- **开头公式**：功能 + 判断同时给出，前两句内完成定位
  - ✅ 「Kimi 出了 X 功能，我测了一天，比 Claude 好用在这一点，但有个致命缺陷——」
  - ❌ 不铺垫背景，不从"让我先介绍一下这个工具的发展历史"开始
- **正文**：每个功能点对应具体使用场景（不是功能列表），新 vs 旧对比让读者理解增量
- **结尾**：实用推荐 + 一句判断。「我用了/推荐/适合 XX 场景」，不升华
- **禁止**：「颠覆」「革命性」等无法被数据支撑的词；没实测就下结论

**宝玉xp（模型/研究层解读）**

实际写法信号：

- **开头公式**：事件 + 一句解读，前两句内给出角度
  - ✅ 「OpenAI 发布新模型——真正值得注意的不是参数规模，是推理链的处理方式变了」
  - ❌ 不说「OpenAI 发布了新模型」然后等到结尾才给判断
- **正文**：每个技术细节后跟一句「这意味着什么」；用类比让概念可理解
- **克制选题**：不是所有新闻都值得写，只写「真的重要」的——克制本身是信任建立

### 公众号版写作规则

**今日一句写法（对标歸藏开头风格）：**
- 有主语（谁/什么）+ 有判断（这说明/意味着/让人警惕）
- FAIL: 「今天 AI 圈很热闹」「又是充满变化的一天」
- PASS: 「Anthropic 今天连出三张牌——不像在更新产品，像在布局渠道」

**发生了什么（对标宝玉「含义层」）：**
- 每条 = 事件 + 「这意味着/说明」（含义不省略）
- FAIL: 「Claude Code 发布 Agent View」
- PASS: 「Claude Code 发布 Agent View：多任务管理从"在十个窗口打游击"变成了"指挥台"——对开发者来说是实质性工作流变化」

**灵感一闪（对标花叔「毒舌类比」+ 宝玉「提炼含义层」）：**
- 花叔风格：用一个意外类比一句话击中
  - 「办了健身卡然后带 18 个朋友去洗澡」 = 对 API 滥用行为的精准击杀
- 宝玉风格：「这意味着你第一次可以……」直接说出含义

**格式规范：**
- 分节：`---`
- 列表：`‣` 前缀
- 无 emoji 装饰
- 禁止词（来自 author-methods.md 各创作者禁忌）：「值得注意的是」「深度解析」「综上所述」「让我们拭目以待」「随着…的发展」「不得不说」「颠覆」「革命性」「各有优劣」

## X（推特/Twitter）

### 标杆：Rowan Cheung / The Rundown AI

**实际发文格式（直接引用其 post 模式）：**

```
Here are today's top AI stories:

▸ [具体事件，一句话结论]
▸ [具体事件，一句话结论]
▸ [具体事件，一句话结论]
▸ [具体事件，一句话结论]
▸ [具体事件，一句话结论]

My take: [一句立场，不是描述，是判断]
```

**风格信号：**
- 每条 bullet 独立可传播，不依赖上下文
- 「My take」必须是判断句，不是「值得关注」
- 整体像「把报纸头版浓缩给你」的密度

**X 版写作规则：**

主推文（1条必发）：
```
📅 MM/DD AI 圈 ·
▸ [故事1，结论句，≤35字]
▸ [故事2]
▸ [故事3]
[今日一句，立场收尾，≤20字]
```

工具推文（选做）：
```
🔧 今日技巧：[工具/命令名]
[具体怎么用，一句话操作说明]
[为什么今天推，时效理由]
```

灵感推文（选做）：
```
💡 [直接从判断开始，不铺垫，≤100字]
```

格式规范：
- 每条 tweet 独立可传播
- Emoji 最多 1 个/推文，开头功能性位置
- Hashtag 最多 2 个，放最后

## 小红书

### 标杆：赛博禅心

**实际风格信号（来自 author-methods.md）：**

- **核心调性**：安静的洞察 + 第一人称真实感。不催焦虑，邀请进入思考空间
- **开头**：生活场景 or 感受切入；或用「以前…现在…」的对比，具体但不夸张
- **段落节奏**：短（2-4 句），大量留白
- **情绪词**：有温度但不极端。不是「爽爆了」，是「挺有意思的」「感觉不一样了」
- **工具实测**：「在什么场景下我怎么用它，感受是什么」，不只说「好用/不好用」
- **观点**：「我自己的感受是……」，给读者留思考空间，不强制下结论

**实际禁忌（直接来自赛博禅心风格）：**
- 高密度信息轰炸
- 「100倍效率」「颠覆认知」式极端标题
- 夸张情绪词

**小红书版写作规则：**

标题公式（选一种）：
- 日报签名式：`MM.DD AI 早知道 · 今天的主角是 [XX]`
- 感受式（赛博禅心风格）：`今天用 AI 做了一件挺有意思的事`
- 对比式：`以前要花一天的事，AI 今天 17 分钟做完了`

开头（赛博禅心式，不冲，有质感）：
- 从今天一件具体的事入手，不是「今天 AI 圈非常热闹」
- 像在跟朋友说「我今天看到一件事，你要听吗？」

分点格式：
```
① [事件名]
[1-2句，我怎么理解这件事，有感受有判断]

② [事件名]
[同上]
```

灵感段（赛博禅心式：不拔高，安静给出）：
```
💡 今天的一个想法

[有具体触发的判断，50-80字，像在跟朋友小声说一件有意思的事]
```

工具推荐（赛博禅心式：使用场景优先）：
```
🔧 今天用到 / 发现的工具

[工具名]：[我在什么场景下用，感受是什么]
[适合：……的人]
[今天为什么推：……]
```

收尾：1句，轻邀请，不说教
- ✅ 「你们有没有类似的感受？」
- ❌ 「建议大家都去试试」

话题标签：3-5 个，`#AI日报 #AI工具` + 当日相关1-2个

## 通用禁止词（三平台共用）

| 禁止词/句式 | 原因 |
|------------|------|
| 值得注意的是 | 废话前缀，直接说为什么 |
| 随着 AI 的发展 | 任何时候都能说，无今日性 |
| 不得不说 | 删掉，直接说 |
| 让我们拭目以待 | 不表态，FAIL |
| AI 正在改变世界 | 格言，不是洞察 |
| 颠覆性 | 用数据支撑，不用形容词 |
| 各有优劣 | 必须有立场 |
| 深度解析 / 全面盘点 | 媒体八股，卡兹克禁忌 |
| 综上所述 | 作文结尾，删掉 |
| 值得期待 | 给出具体期待什么 |

## 快速对照：三版风格差异

| 维度 | 公众号 | X | 小红书 |
|------|--------|---|--------|
| 语气 | 有立场/有判断，不煽情 | 简洁，bullet密度 | 第一人称，安静有感受 |
| 情绪词 | 无，靠判断力 | 无，靠密度 | 轻度，有温度不夸张 |
| 今日一句位置 | 开头直接给 | 末尾收束 | 融入开头氛围 |
| 灵感一闪 | 段落式，有类比 | 独立一条推文 | 短，「小声说」感 |
| 工具推荐 | 立场+怎么用 | 操作指令式 | 使用场景+感受 |
