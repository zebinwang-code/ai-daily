# XHS 封面图模板规范

> 小红书所有标杆创作者（歸藏/卡兹克/花叔/赛博禅心）配图率 ≥ 80%，封面图是点击率最重要变量。
> 生成工具：huashu-design skill（花叔自制）或 canvas-design skill。

---

## 基础规格

| 参数 | 规格 |
|------|------|
| 尺寸 | 3:4 竖版，建议 1080×1440px |
| 文件格式 | PNG / JPG |
| 文字行数 | 标题 ≤ 2 行，副标题 ≤ 1 行 |
| 字号 | 标题 ≥ 80px，副标题 ≥ 40px |

---

## 三种封面风格（按话题选一种）

### A. 信息卡型（AI 资讯首选）
适用场景：多条新闻汇总、工具教程、评测对比

```
┌─────────────────────────────┐
│  📅 5.13  AI 圈              │  ← 日期 + 分类（小，顶部）
│                             │
│  你90%的AI账单              │  ← 大字标题（2行，居中）
│  都在白白浪费               │
│                             │
│  ── Karpathy 今天说了啥 ──   │  ← 副标题（小，居中）
│                             │
│  [视觉元素：代码/数字/图标]  │  ← 下半部分装饰
└─────────────────────────────┘
```

**配色方案 A（卡兹克/歸藏风格）：**
- 背景：#0A0A0A（近黑）
- 标题：#FFFFFF（白）
- 强调：#FF6B35（橙）或 #00D9FF（青）
- 副标：#888888（灰）

### B. 截图+批注型（工具测评首选）
适用场景：具体工具演示、对比截图、使用前后

```
┌─────────────────────────────┐
│  [产品截图，占 60% 面积]     │
│                             │
│  ┌───────────────────┐     │
│  │  标题文字，2行     │  ← 白色底卡覆盖截图下方
│  │  副标题，1行       │
│  └───────────────────┘     │
└─────────────────────────────┘
```

**配色方案 B（花叔风格）：**
- 截图真实，不滤镜
- 底卡：白色半透明（opacity 0.9）
- 文字：#1A1A1A（黑）
- 强调：#FF4757（红）

### C. 场景感型（赛博禅心风格）
适用场景：个人感受、洞察类、思考类

```
┌─────────────────────────────┐
│                             │
│  [渐变或纯色背景，清新]      │
│                             │
│       「标题文字」           │  ← 引号包裹，文艺感
│                             │
│       副标题一句话           │
│                             │
│              ·  ·  ·        │  ← 简洁装饰
└─────────────────────────────┘
```

**配色方案 C（赛博禅心风格）：**
- 背景：#F5F0E8（暖米）或 #E8F4FD（浅蓝）
- 标题：#2C2C2C（深灰）
- 强调：#5B9BD5（蓝）
- 装饰：少，留白多

## 生成指令模板

### 使用 huashu-design skill 生成

调用 `/huashu-design` 时传入以下 prompt：

```
生成一张小红书封面图，信息卡风格：
- 背景：纯黑 #0A0A0A
- 顶部小字（灰色）：📅 MM.DD  AI 圈
- 中部大字（白色，粗体，两行）：[标题第一行] / [标题第二行]
- 底部小字（灰色）：[副标题]
- 右下角橙色圆点装饰
- 尺寸 1080×1440
```

### 使用 canvas-design skill 生成

```
设计一张 3:4 AI 日报封面卡片：
主题色 #0A0A0A，标题「[标题]」白色大字居中，
副标题「[副标题]」灰色，顶部日期「MM.DD」
极简风格，无多余装饰。
```

## 本日图片 checklist

生成后确认：
- [ ] 文字清晰可读（不小于 40px）
- [ ] 标题完整显示，未被裁切
- [ ] 主视觉元素不遮挡文字
- [ ] 颜色对比度足够（白字/黑底或反之）
- [ ] 尺寸 3:4 竖版

## 标题→图片标题映射

| 平台标题 | 图片标题（更短，≤10字） |
|---------|----------------------|
| 「你90%的AI账单都在浪费，三条改了就省」 | 「90%账单在浪费」|
| 「Karpathy：你90%的AI账单都在浪费」 | 「Karpathy 今天说」|
| 「同一天：法院判了，律所也用了」 | 「AI 法律战同天开打」|

图片标题比推文标题更短——图片只需要钩子，正文在图下方。
